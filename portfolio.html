프로젝트 개요

임신 준비 과정에 흩어진 기록과 비교 업무를 세 가지 간단한 입력·처리·출력 프로그램으로 통합했습니다.

핵심 기능

각 기능은 독립적으로 실행되며 입력값 저장, 수정·삭제와 모바일 화면을 지원합니다.

산후조리원 비교

비용과 편의조건을 같은 기준으로 비교합니다.

  • 비용·거리 입력
  • 서비스 조건 기록
  • 참고점수 자동 계산
실행

입력 → 처리 → 출력

복잡한 서버 없이 HTML과 JavaScript만으로 핵심 데이터 흐름을 구현했습니다.

1. 입력

준비항목, 이름 후보, 조리원 비용과 조건을 사용자가 입력합니다.

2. 처리

완료율, 선호도 정렬과 조건별 참고점수를 자동 계산합니다.

3. 출력

결과를 카드, 진행률과 비교 목록으로 이해하기 쉽게 표시합니다.
