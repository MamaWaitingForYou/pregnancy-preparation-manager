# 임신·출산 준비 통합 관리 프로그램

임신 준비부터 출산 후 산후조리원 선택까지 필요한 정보를 기록하고 비교하는 웹 프로젝트입니다. 별도의 설치 없이 HTML 파일을 브라우저에서 실행할 수 있습니다.

## 프로그램 구성

### 1. 임신 준비 건강 체크리스트

- 건강·생활 준비항목 확인
- 새로운 항목 직접 추가 및 삭제
- 준비 완료 체크와 전체 완료율 표시

### 2. 아기 이름·태명 기록장

- 이름·태명 후보, 뜻, 구분과 메모 등록
- 후보별 선호도와 즐겨찾기 설정
- 선호도순 정렬, 수정 및 삭제

### 3. 산후조리원 비교 프로그램

- 조리원명, 2주 비용, 거리와 시설 만족도 입력
- 마사지, 보호자 숙박, 모자동실과 병원 연계 여부 기록
- 비교점수순 결과 표시, 수정 및 삭제

## 입력 → 처리 → 출력

| 프로그램 | 입력 | 처리 | 출력 |
| --- | --- | --- | --- |
| 건강 체크리스트 | 임신 준비 항목과 완료 여부 | 완료 항목 수와 완료율 계산 | 준비 목록과 달성률 |
| 이름·태명 기록장 | 후보명, 뜻, 구분, 선호도 | 즐겨찾기 및 선호도순 정렬 | 후보 비교 목록 |
| 산후조리원 비교 | 비용, 거리, 시설과 서비스 | 조건별 참고점수 계산 | 비교 결과와 정렬 목록 |

## 실행 방법

1. 저장소의 파일을 내려받습니다.
2. `index.html`을 더블클릭합니다.
3. 원하는 프로그램의 **실행하기** 버튼을 누릅니다.

## 사용 기술

- HTML5
- CSS3
- JavaScript
- Local Storage

## 데이터 저장

입력한 내용은 현재 브라우저의 로컬 저장소에 저장됩니다. 서버로 전송되지 않으며 브라우저 데이터를 삭제하면 기록도 사라질 수 있습니다.

## 주의사항

이 프로그램은 학습 및 개인 기록을 위한 보조 프로그램입니다. 건강관리와 예방접종은 의료진과 상담하고, 산후조리원 선택 전 실제 비용·서비스·환불규정과 응급대응 체계를 해당 기관에 확인해야 합니다.
